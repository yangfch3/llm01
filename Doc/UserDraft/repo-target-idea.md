# 关于仓库的一些想法 - 起步文档

## 背景

我是一个资深的游戏开发工程师，同时网页、服务器、Python、计算机基础等各方面知识也有储备。

目前我对 LLM 的制作与训练产生了浓厚的兴趣，希望借助 AI 帮助我开启 LLM 的学习之旅，最终能掌握 LLM 训练的全链路过程，产出一个能与我对话、有基础智力的模型。

我的信息：

1. 会在 Windows/Mac 双平台上开发
2. Python 版本 3.12.x

## 想用这个仓库做什么

1. LLM 领域的前置知识学习
2. LLM 制作与训练全链路的学习
3. 搭建 LLM 的环境，并编码落地整个训练过程，产出训练成果

## 希望最终的产出是

1. 课程大纲（在 Doc/Courseware）
2. 课程章节及其 markdown 课件（在 Doc/Courseware）
3. 课程练习代码（在 Playground 下）
4. 一个 LLM 训练的全链路项目（在 Echo 下），该 LLM 的需求：
  * 代号为 Echo
  * 智力能达到初中生的水平
  * 能和我进行基础的对话
  * 可以本地运行在 RTX 3060 12GB 级别的 GPU 上

## 如何 Startup 以及与 AI 协作

1. 阅读并理解此文档
2. 针对本文档不清晰、待明确的部分与用户一起查漏补缺 
3. 规划项目的目录结构（可以先理解我已经建好的目录，不合理的地方可以改）
4. 输出一份项目 Startup 策划案 - 整个项目的根基文档
5. 输出一份项目的计划书 - 所有未来要做的事项的整理与拆分

## 一些约束与期望
1. 希望本仓库的依赖环境独立（使用 uv/venv/... 等）
2. 希望未来这个仓库开源可以对其他 LLM 入门者起到良好的引导作用
